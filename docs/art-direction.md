# 美术方向

## 基调与依据

以明代中后期宫廷建筑、服饰轮廓、礼仪器物为松散灵感，但保持架空大晟朝设定。画面像一册略带幽默的工笔宫廷手记：暖象牙纸、墨色文字、克制的朱砂、暗玉青与旧金，不采用霓虹仙侠效果。

## 生肖视觉体系

- A：角色直接呈现生肖动物形态，穿着历史宫廷服饰。
- B：角色保持人类外观，仅以轮廓、纹样、配饰、姿态与性格编码生肖。
- A.5（本项目首选）：角色首先是优雅的古代中国幻想人物，再以克制的耳形、瞳孔、尾部、角形发饰或动物纹样令生肖身份一眼可辨。

目标观感是“严肃宫廷剧理所当然地住着一群生肖人物”。角色本人绝不对生肖特征感到惊奇。不得画成儿童生肖贴纸、吉祥物服装、通用 furry、现代兽娘卖点或霓虹抽卡角色。

首发视觉编码：卯兔使用柔和直立轮廓、月白与玉色、耳形发饰；寅虎使用锐利眼妆、山虎纹、朱砂与主事姿态；子鼠使用小而敏捷的轮廓、圆耳形官帽、细须纹与消息札；丑牛使用宽稳轮廓、角形发饰与耐用织物。

文件名采用 `category_subject_variant_v01.webp`，如 `portrait_shen-lingyi_calm_v01.webp`。每个人物固定脸型、发髻高度、服装主色、配饰层级和姿态语言；表情变化不得改变身份特征。不得模仿可识别演员、现存影视角色或具体剧集造型。

当前 CSS 图形均有固定容器。替换时保留容器比例、`object-fit` 规则、替代文本与装载空间，避免布局跳动。

## 双美术与生成流程

主要角色最终同时拥有正式宫廷立绘与生肖 Q 版。正式立绘用于对话、关系时刻和御前场景；Q 版只用于数值变化、技能触发、事件小结等短促反馈，不能破坏历史氛围。

AI 生成资产必须先建立角色母版，固定脸型、发髻、生肖特征、服装层级、主辅色与眼线高度；表情变体以母版作为身份参考，仅改变表情。每次生成需保留最终提示词、生成路径和版本号，人工检查手部、服制、重复纹样、错误文字与角色漂移。不得要求模仿可识别演员或现有影视角色。
