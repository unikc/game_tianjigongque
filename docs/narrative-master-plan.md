# 《天机宫阙》第一季完整叙事总纲

## 创作边界

第一季为成人向宫廷政治剧情，可以出现死亡、投毒、流产暗示、刺杀与政治处决。镜头不追求血腥展示，重点放在选择、责任、证据和长期余波。涉及妊娠与失去孩子的情节不作为笑料、升级材料或单纯推动他人行动的工具；玩家可以选择介入、揭露、隐瞒或退出，但不能用一次“正确选项”抹去创伤。

## 核心命题

宫里的位置是谁给的？一个人为了保住位置，可以让谁失去名字、孩子、自由或性命？

第一季表面事件从一只被调换的绣鸭开始，逐渐揭开“空印案”：有人利用尚宫局、内务府与宗室之间互不核验的文书，伪造调令、挪走赈灾银，并为即将到来的皇位危机准备兵粮。第一章的金粉和第二章的反向刮痕，都是同一条文书链留下的痕迹。

真相不是单一恶人所为：太后母族最早建立暗账；皇后沈令仪为了阻止宗室兵变，曾默许其中一部分继续运转；顾明华发现后试图夺取这套网络；高福安靠传递碎片消息生存。玩家最终必须决定，是接管、公开、摧毁，还是离开这套制度。

## 主要角色弧线

### 玩家角色

从一个需要别人给位置的新人，成长为能够决定位置如何分配的人。她可以成为皇后、摄政者、情报掌事、改革者、富商、史官或无名出宫者，也可能死于自己维护的秩序。

### 皇后 · 沈令仪

秩序型盟友与潜在最终对手。她不是空印案的创建者，却为了避免即时政变掩盖了部分真相。高关系时会把真正账册交给玩家；低关系时会先下手软禁玩家。她的结局可以是留任、退居、被废、共治或死亡。

### 昭仪 · 顾明华

野心型盟友与竞争者。她相信权力不会奖励等待的人。她邀请宗室女眷制造第二章的席位冲突，是为了测试谁能改动名册。她可以成为玩家最锋利的盟友、爱情线对象、政变合作者或被玩家送上刑场的人。

### 内侍 · 高福安

信息网络的活接口。他曾替空印案传过一封导致师父死亡的调令，因此保存了大量副本。关系高时愿意交出“鼠册”；关系低时会把玩家的秘密卖给出价最高者。他可能成为内廷总管、证人、替罪羊或与玩家一同出宫。

### 皇帝 · 萧承元

聪明但长期借“平衡”逃避责任。他知道国库有缺口，却不知道缺口已经变成兵粮。玩家可以让他成为真正承担后果的君主，也可以架空、废黜或在刺杀中失去他。感情线不是自动通往权力的捷径。

### 羽林副统领 · 裴照南

武将世家，奉命调查宫门调令。她把纪律视为救命之物，却逐渐发现军中粮册同样被伪造。她可以成为玩家的军事盟友、感情线对象、政变执行者或拒绝所有阵营的守门人。

### 太医 · 温疏雨

负责辨认毒物与妊娠脉案。她曾被迫修改一份脉案以保护一位遭家族利用的妃嫔。她代表“救一个具体的人”与“公开全部真相”之间的冲突，可成为改革太医院的伙伴、感情线对象或被制度牺牲的证人。

### 林答应 · 林栖梧

第二章被刮去名字的人。她看似柔弱，实际记忆极好，偷偷收集被删除者的名字。她可能成为玩家的证人、被救下的朋友、对玩家妥协的控诉者，或第三位因名册而“消失”的人。

## 十二章结构

### 第一章《绣鸭献瑞》——位置从笑话开始

- 已实现：入宫、三位核心 NPC 会面、绣品被调换、御前应答与初封。
- 关键线索：长春宫金粉、绣线覆盖、礼物流转名册。
- 核心选择：承担、调查、圆场、逃避。
- 奖励：称号“御前初见”、道具“御赐东珠”。

### 第二章《一席之争》——谁有资格坐下

- 已实现：两宫同时传召、名册刮改、顾明华施压、宫宴空席。
- 关键线索：反向刀痕证明改册者不属于尚宫局。
- 核心选择：先例、机构、人情、自我牺牲或重构问题。
- 奖励：证物“刮痕名册”。

### 第三章《合欢香冷》——第一具尸体

1. 林答应在宴后收到玩家名义送出的合欢香。
2. 次日宫女青禾死在香房，林答应中毒但可能获救。
3. 温疏雨判断毒物并非香料，而是盒盖内层的慢性矿毒。
4. 御赐东珠可用于比对盒扣上的珍珠粉，证明礼盒来自御库外仿制。
5. 玩家可救林答应、追凶、保护温疏雨或先洗清自己。
6. 若只顾自保，林答应死亡；若仓促指认顾明华，真正文书链转移。

分歧结果：林答应生还并成为证人；林答应死亡留下姓名册；温疏雨遭停职；玩家背上“借香杀人”的流言。

### 第四章《雨夜空印》——没有字的圣旨

1. 高福安交来一张盖印却无文字的旧纸。
2. 暴雨封宫，当夜三道不同调令使用了同一枚印。
3. 玩家潜入文书房、跟踪传令内侍或把空印交给皇后。
4. 裴照南在宫门截下一车“药材”，车中实际是军粮账簿。
5. 顾明华提出合作：保留空印，反过来伪造一道调令诱出上家。

分歧结果：获得空印、烧毁空印、皇后收走空印；裴照南信任或监视玩家；高福安暴露一份副册。

### 第五章《未落之子》——一份被改写的脉案

1. 惠嫔在赏花宴上腹痛，宫中传出流产消息。
2. 脉案显示她从未怀孕；她的家族却已借“皇嗣”取得赈灾差事。
3. 惠嫔承认自己配合假孕，是为了保住被家族扣押的妹妹。
4. 温疏雨曾修改脉案，但没有下毒；真正的药来自宗室女眷。
5. 玩家可公开假孕、制造“平安退养”的体面结局、交换人质，或让谎言继续。

分歧结果：惠嫔活着离宫；惠嫔被赐死；妹妹获救；温疏雨承担罪名；玩家得到赈灾名单。此章不提供零代价完美解。

### 第六章《河决千里》——宫墙外的人命

1. 河道决口，赈灾银少了三成，失踪数目与空印账吻合。
2. 玩家被派去整理捐银，可选择留宫查账或随裴照南短暂出宫。
3. 商贾出身可追踪票号，翰林出身可辨伪账，武将出身可查军粮。
4. 玩家第一次看到宫廷选择在百姓身上的后果。
5. 顾明华主张扣住证据换取权力；沈令仪主张先保住赈灾运输。

分歧结果：即时救灾但主谋警觉；冻结赃银导致物资延误；秘密补足缺口；公开账目引发朝局震荡。

### 第七章《春猎惊弦》——箭从谁的方向来

1. 春猎途中出现针对皇帝的刺杀。
2. 箭簇来自羽林库存，调拨文书使用空印格式。
3. 玩家可救皇帝、保护证人、追击刺客或借乱取走总账。
4. 裴照南发现自己的兄长签过粮册，却可能是被冒名。
5. 若皇帝死亡，游戏提前进入摄政分支；若重伤，玩家获得临时决策权；若无伤，他开始怀疑所有人。

分歧结果：皇帝生还、重伤或死亡；裴照南忠诚、离队或被捕；玩家获得“断箭”。

### 第八章《凤印两面》——皇后的罪与理由

1. 沈令仪承认自己发现空印案已有三年。
2. 她曾放走一名主犯，以换取宗室军队不入京。
3. 顾明华公开一半证据，逼皇后交权。
4. 玩家可站皇后、站昭仪、调停、公开全部证据或秘密接管网络。
5. 林栖梧若活着，会指出皇后“为了多数人”删除过哪些具体名字。

分歧结果：皇后留任、退居、被废或与玩家共治；顾明华晋位、软禁或转入地下；玩家阵营正式成形。

### 第九章《十二宫火》——证据会燃烧

1. 保存副册的十二宫库房起火。
2. 玩家只能优先救人、救账、救御印或追纵火者。
3. 高福安被困，其中一份账册藏在他义父牌位后。
4. 火势蔓延至冷宫，那里关着被宣布“病亡”的旧案证人。
5. 若玩家过去频繁牺牲小人物，宫人不会冒险帮助她。

分歧结果：不同证人与证物永久失去；高福安生死确定；获得“灰烬账页”；宫人关系成为公开政治力量。

### 第十章《金殿无主》——谁来签下一道命令

1. 皇帝重病或已死，边军逼近京城。
2. 太后要求拥立幼年宗亲；皇后主张封锁宫门；顾明华主张先控制禁军。
3. 玩家必须在一夜内决定粮、门、印分别交给谁。
4. 三件权力物不能由同一方安全持有，但分开也可能互相背叛。
5. 御赐东珠若仍持有，可证明一道“皇帝口谕”所附赏物是假货。

分歧结果：合法摄政、军事接管、宗室傀儡、三方共治或全面政变。

### 第十一章《宫门血诏》——最后一次可以回头

1. 政变方持伪诏入宫，裴照南守最后一道门。
2. 玩家此前留下的人、证据和道具决定可用方案。
3. 可以公开广播账目瓦解军心、用空印反制、交出主谋换停战、刺杀领袖或打开宫门让百姓与朝臣见证。
4. 顾明华可能要求玩家处决沈令仪；沈令仪可能要求玩家牺牲顾明华。
5. 玩家可拒绝二选一，但必须拿出足够政治资本承担后果。

分歧结果：无血交权、宫门战、秘密处决、双方存活的脆弱和解，或玩家死亡。

### 第十二章《天明以后》——位置如何留下

1. 空印案真相公开、部分公开或永久封存。
2. 玩家处理沈令仪、顾明华、高福安、裴照南、温疏雨与林栖梧的最终命运。
3. 玩家决定是否保留后宫旧制、建立女官议事、开放宫门审计或接管秘密网络。
4. 最后一个选择不是“选谁”，而是玩家愿意成为怎样的人。
5. 结尾以多年后的一件普通小事检验改革是否真实：一名无位新人是否仍会从名册上消失。

## 人生路线

### 凤座线：公开权力

高名望、高礼仪、掌握凤印或获得沈令仪支持。优势是能够直接改变制度；代价是每次妥协都会成为日后的先例。

### 墨网线：秘密权力

高谋略、保存空印与鼠册、维持高福安关系。优势是能提前改变事件；代价是玩家逐渐成为自己最初追查的那类人。

### 青简线：救人与改革

高人情、才学，与温疏雨、林栖梧结盟，优先保住证人与具体的人。优势是获得民间与宫人支持；代价是可能错过迅速夺权的机会。

### 开门线：自由与宫外人生

保留银钱、商路和出宫证件，不依附唯一阵营。玩家可以离宫经商、行医、著书或建立女学；这不是“失败退出”，而是拒绝用宫廷定义成功。

## 正式结局

1. **《凤座无眠》**：成为皇后，改革部分制度，却必须继续处理权力留下的新问题。
2. **《垂帘听政》**：皇帝死亡或退位，玩家成为摄政者；国家稳定，但私人生活几乎消失。
3. **《两宫共治》**：与沈令仪达成权力分置，困难但避免清洗。
4. **《明华同盟》**：与顾明华共同夺权；高信任时成为危险而真诚的伙伴，低信任时遭她反制。
5. **《墨中无名》**：成为秘密情报掌事，历史上没有封号，却决定许多封号。
6. **《青简新章》**：与温疏雨改革太医院和女官制度，离开争储中心。
7. **《守门之人》**：与裴照南整顿军粮和宫防，权力有限但边界清楚。
8. **《宫外春深》**：主动离宫，以商路、医术或书院建立另一种影响力。
9. **《一卷宫史》**：放弃官位，公开空印案全部姓名，成为被禁又流传最广的史书作者。
10. **《金笼》**：获得最高位分却失去所有可信盟友，活着成为制度的装饰。
11. **《代罪之人》**：为保全某个角色或阻止战争承担主谋罪名，被流放或处决。
12. **《宫门未开》**：证据尽失、盟友离散，政变成功；玩家存活，但旧制度以新名字继续。

## 关系结局原则

- 感情结局与政治结局分开计算；相爱不自动意味着共同执政。
- 皇帝、顾明华、裴照南、温疏雨均可形成深层感情路线。
- 高福安与沈令仪以复杂知己/政治共同体为主，不强制浪漫化。
- 玩家可以不进入任何恋爱关系，单身结局拥有同等内容与尊严。
- 任何感情对象都可能因价值观冲突离开玩家，即使好感很高。

## 关键持久状态

- `lin_alive`：林栖梧是否活到后期。
- `emperor_state`：健康、重伤、死亡。
- `empty_seal_state`：皇后持有、玩家持有、顾明华持有、焚毁。
- `ledger_evidence`：名册、鼠册、军粮册、灰烬页的组合。
- `palace_staff_support`：宫人是否愿意在火灾与政变中帮助玩家。
- `public_truth`：真相公开程度。
- `institutional_reform`：制度改革程度。
- `personal_freedom`：玩家保留的宫外资源与退路。

## 道具叙事规则

道具提供侧路，不提供万能正确答案。御赐东珠可验明礼物来处，也会暴露玩家受到御前关注；空印可诱敌，也能让玩家成为伪诏共犯；刮痕名册能保护被删除者，也会证明玩家早已知情。每件关键道具至少有两次使用机会，并允许玩家选择一直不用。

## 编剧实施顺序

1. 将第三至第十二章分别拆成 6–10 个可玩场景。
2. 为每章建立进入条件、不可逆选择、证据变化和角色余波。
3. 先完成四条人生路线均可抵达结局的骨架。
4. 再补关系专属场景、生肖解法、出身解法和道具奇效。
5. 最后进行全路径遍历，检查“明显正确选项”、假分支和角色遗忘。
