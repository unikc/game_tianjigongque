# 游戏设计

## 核心循环

读场景 → 判断未明说的意图 → 选择回应 → 获得数值与关系反馈 → 承担延迟后果 → 获得位分和风格归纳。第一章目标时长约五至八分钟。

## 玩家控制与状态

玩家选择姓名、出身及每次回应。公开状态为八项属性与三段人物关系；隐藏状态包括行为标签、选择历史、人物动机和评分权重。随机性由每局种子控制，重载不会改变裁定。

生肖命宫与位份彼此独立。位份表示宫中权力，生肖表示角色如何行动。首发提供卯兔、寅虎、申猴、丑牛四种命宫，并分别以静观、直取、机变、实干塑造玩法；专属选项是侧向解法，不保证优于普通回应。

## 第一章流程

标题 → 出身 → 入宫答话 → 皇后 → 顾昭仪 → 高内侍 → “绣鸭献瑞” → 御前裁定 → 首封结果 → 待续。跨场景组合（如出身与处理方式、证据习惯与调查选择）会影响最终分数，单一答案不能直接保证最高位分。
