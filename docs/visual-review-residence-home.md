# 寝宫主页视觉审查记录

日期：2026-08-08
审查：Imperial Art Director

## P0

- 320px 下行动卡使用两列，最后一项横跨整行；触控区至少 44px。
- 辅助文字不得小于 12px，关键状态不得小于 13px。
- 设置齿轮位于寝宫标题右上角，44×44px；重新入宫置于底部设置面板，并二次确认。

## P1

- 页面顺序固定为：居所、即时状态、当前剧情、皇帝关系、今日行动、我的成长。
- 即时状态固定为位分、闲暇、体力、银钱；帝驾并入皇帝关系；随身物成为居所下方细条。
- 同级模块统一使用 `PalacePanel`：同纸色、同金线、同 8–10px 内边距。红色只表示主线紧要，玉色表示状态与行动，金色表示奖励与礼制。

## P2

- eyebrow 12px；普通标签与成本 13px；数值和动作名 17–18px；正文 15–16px。
- 行动卡固定为动作、主要结果、消耗/风险三层；成本顺序为闲暇、体力/银钱、注目/低调。
- 成长区只保留修习点和属性进度，避免重复显示已在顶部出现的体力、银钱等资源。

## P3

- 齿轮采用细线铜钮感，尊重 reduced-motion。
- 分区间距统一 12px，组件内间距统一 8px。
