# 政治合法性与体面台阶

## 设计原则

政治合法性不是一条数值，也不是“宠爱够高便可以做任何事”。它只回答一个有情境的问题：**谁可以凭什么依据，在什么职位上行使哪一部分权力，并为此作出什么让步。**

- 每项依据必须绑定职位、受益人和来源选择；同一依据不能自动跨职位使用。
- 证据只证明事实。假口谕、皇帝伤情与文书真伪不能自动授予摄政权。
- 宠爱、信任、修习、位分与持有珍藏都不是合法性依据。
- 玩家提出主张的选择不能反过来成为该主张的依据。
- 判断采用多套命名的“或”方案，不累加为万能分数。
- 依据不足时不立即判输；NPC 必须指出具体缺口，并提供会付出真实政治代价的体面退路。

## 当前原型：第十章摄政署名

玩家独自署名时，以下三套依据任一成立即可被承认为摄政：

| 方案       | 所需来源                        | 政治含义                                     |
| ---------- | ------------------------------- | -------------------------------------------- |
| 旧例与共署 | 第八章修习突破 + 第十章顾氏共署 | 旧例允许玩家复核，现实联盟承认玩家落笔。     |
| 公议与自限 | 第八章女官议事 + 第十章三方分权 | 有公开记录，也有主动限制个人权力的承诺。     |
| 共管与让步 | 第八章两宫共管 + 第八章居中调停 | 玩家曾被写入共管职责，并以让步换取有限授权。 |

`imperial-mandate` 已保留为合法性类型，但当前剧情没有任何有效来源。皇帝宠爱、信任、安危或隔帘听政均不得被推断为帝王明授。

## 质询与补救

若玩家只有事实证据而无授权，崔太后会提出命名质询：“凭哪一条旧例、哪几个人的名字，说这是摄政，不是夺权？”玩家仍可：

1. 放弃独署，改为沈令仪与顾明华共署；
2. 让朝臣入殿，改为公开联署；
3. 若曾找到旧宫规，只代行至帝驾回宫，并把权限限定为复核。

前两条牺牲个人权力，第三条牺牲权力范围与期限。所有分支均回到既有第十章结算，不新增章节，也不制造无提示死局。

## 后续接入边界

- 新的政治主张应新增独立 `LegitimacyQuestion`，不得借用摄政方案。
- 第十二章“登凤座”仍存在纯数值晋位路线，是后续应迁移到继承/凤位合法性问题的已知风险；F02 不重复搭建第二套结局系统。
- 结局可以引用玩家曾采用的方案标签，但不能仅凭一个结局选择回填此前不存在的合法性。
