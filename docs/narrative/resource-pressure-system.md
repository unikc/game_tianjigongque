# 体力与银钱：风险交换系统

## 玩家命题

资源不是阻止玩家继续故事的门锁，而是决定她如何解决问题：亲自承担、花钱安排，或欠人情借力。身体的债在危机中讨还，银钱的债在人情与证据中讨还。

## 当前可玩闭环

- 体力、银钱维持 0–10，并显示稳定四档：充沛（7–10）、平稳（4–6）、吃紧（2–3）、危急（0–1）。
- 每次寝宫行动消耗 1 闲暇。修习与夜谈消耗体力，走动消耗银钱。
- 静养恢复体力：危急时 +3，其余 +2；景和宫额外 +1。
- 每章可筹措一次：体力 −1、银钱 +2、宫廷注目 +2，并欠高福安一份人情（关系 −10）。
- 每章结束自然恢复 1 体力；按位分领取俸例，再扣除居所日常用度。升位提高收入，也提高维持体面的成本。
- 连续两章以低体力或低银钱结算，会在行录中提示并解锁对应困局支线。玩家得到补救路线，但必须接受名望、关系或线索上的一种代价。
- 旧存档迁移到版本 8 时补齐资源压力记录，不改变既有剧情、人物关系与珍藏。

## 连续性与平衡约束

- 主线不得因体力或银钱为零而无路可走。
- 高资源提供主动权，不提供自动正确答案；低资源提供危险替代路线，不自动死亡或降位。
- 一次资源困局最多造成一个主要后果与一个记忆标签，避免惩罚螺旋。
- 银钱不能直接购买皇帝信任、制度认同、长期忠诚或凤位。
- 宠爱与信任继续独立；资源只通过玩家如何使用它们间接影响晋位路线。
- 第七章仍不可同时保全皇帝、证人与命令；体力只能改变承担方式。

## 后续挂接顺序

1. 第三、四、七、九章增加“亲历／花钱／借力”的结果变体。
2. 增加每章一次的轻量备办（备药、买消息、托人），不扩展为新背包系统。
3. 在人物页记录尚未偿还的欠情；在后续已有场景兑现，而非另开通用商店。
4. 章末结果展示俸例、日常用度、体力伤耗和欠情变化。
