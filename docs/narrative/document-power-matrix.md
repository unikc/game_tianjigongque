# 文书权力矩阵

## 目的

第一季的权力主线不是“收集更多纸”，而是控制一份事实如何成为可执行、可追责或可公开的记录。E08 统一现有文书，不新增平行证据系统。

## 生命周期

| 阶段 | 叙事含义                                 | 不能自动证明什么                 |
| ---- | ---------------------------------------- | -------------------------------- |
| 持有 | 玩家或其阵营保有原件、拓样或关键副本     | 持有不等于真实，也不等于合法取得 |
| 查验 | 玩家见过纹样、笔迹、来处或矛盾           | 查验不等于能让别人相信           |
| 复核 | 有第二来源、见证、制度记录或实物相互印证 | 复核仍可能牵连无辜或暴露经手人   |
| 流转 | 文书被交给阵营、用作谈判、命令或筹码     | 流转会改变谁能删改与反咬         |
| 公开 | 内容进入朝议、宫门、民间或正式审理       | 公开不等于能治理公开后的局面     |

## 现有证据链

| 文书链       | 首次功能                   | 中期权力                   | 后期风险                           |
| ------------ | -------------------------- | -------------------------- | ---------------------------------- |
| 席位名册     | 证明名字和位置可被刮改     | 追查谁能让记录“生效”       | 证明玩家很早便知宫中删名           |
| 脉案         | 区分救人、造假与家族胁迫   | 控制温疏雨证言和惠嫔退路   | 真相公开可能牺牲被保护的人         |
| 空印调令     | 证明印与文字可以分开制造   | 诱敌、反证或交由皇后保管   | 玩家可被指为伪诏共犯               |
| 赈银／河堤账 | 把宫廷手段连接到百姓损失   | 冻结、补缺、公开或留作筹码 | 经手所有账目者最适合被问责         |
| 军粮／宫门令 | 连接春猎刺杀、边军与空印   | 决定门、粮、令由谁执行     | 假令和真命令可能都经玩家之手       |
| 凤印名册     | 揭示沈令仪的妥协及被删名字 | 使共治、废后、公开成为可能 | 玩家继承的不只是凤印，也是旧账     |
| 假口谕／血诏 | 在最高权力真空中辨真伪     | 瓦解军心、停战或秘密交易   | 所有阵营都能把文书网络归到玩家名下 |
| 三路试探札   | 用互斥假消息辨认失守环节   | 封查、换路或清查收件链     | 错误问责会制造冤责并促使真实链改路 |

## 连续性约束

- 空印案仍是多方利用的制度漏洞，不得被重写为单一超级反派设计。
- `arsonPatron` 和 `wenLoyalty` 的种子真相不由文书足迹推导或泄露。
- `leakLink` 与 `arsonPatron`、`wenLoyalty` 独立：它只回答消息从复核副本、内递路线或收件宫人哪一环流出，不回答谁下令纵火或谁必然通敌。
- 西档青线、御药院路牌与长春宫琴匣三项反应互斥；单一反应只产生 `belief_leak:*`，反应与对应独立观察同时成立才产生 `known_leak_link:*`。
- 持有、赠出、焚毁、证人死亡与公开程度必须继续分别生效。
- 第四章奖励“空印纹样”只表示玩家保留了可识别的拓记；只有 `empty_seal_player` 表示控制原件，`empty_seal_queen` 表示已交皇后，`empty_seal_burned` 表示原件已毁。
- 文书足迹只产生选择和风险，不是可见分数、晋位门槛或自动坏结局。
- “文书中心度”只表示他人容易把多条链归到玩家名下；可归责行为另行记录。未来指控必须同时具备中心度、至少一项具体行为，以及一个有动机且确实知情的指控者。
- 现有《代罪之人》结局承接此弧，不新增一个功能重复的“真正替罪结局”。

# 谢明微与复核阶段

谢明微影响的是材料进入正式档案前的 `examined/authenticated/circulated` 边界：她可记录来源、版本、见证和异议，不能创造原件、鉴定医理、决定罪责或授予政治合法性。第八章的四种复核结果分别永久留下异议附卷、窄范围证词、玩家具名责任或两宫并行异议副本。
