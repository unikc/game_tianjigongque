# 天机阁 · 秘录与谶语（E03）

## 为什么需要这座阁

改造前有两个互相独立的缺口：

1. 游戏叫《天机宫阙》，但「天机」全库只出现在标题画面、`layout.tsx` 的 metadata 与 backlog 里一条 `PLANNED`。**玩家看见的第一个设定是空的。**
2. `hidden-truth.ts` 里三条种子真相在决定第五、八、九章的走向，玩家却没有任何**主动**接触它们的入口，只能被动地在场景里撞见。

天机阁把这两个缺口合成一个东西：**它是玩家面向隐藏真相的唯一界面。**

## 天机不是预言

阁主卫夷则读不了任何东西，是别人念给她听。她的本事不是「看见」，是四十年间听过太多卷档，因此记得同一种笔迹在哪几卷里出现过。

> 「别人以为我们能看见明天。其实我们只是把昨天记得比别人细。同一只手写过的东西，早晚会露出同一个习惯。」

这条设定与空印案是**同一条物理法则**：文书决定什么是真的。天机是别人没读过的记录里能推出来的规律，不是神通。

**任何暗示她「因盲而通神」的写法都必须视为 bug。** 她的失明在登场时不作解释，也不与能力构成因果。

## 三条硬规则

### 一、谶语只给 `belief_*` / `hint`，永不给 `known_*`

她不回答问题，只告诉你**该看哪里**、或**排除哪一段**。玩家仍然要自己下注。

| 类型        | 谶语       | 给出的东西                                       |
| ----------- | ---------- | ------------------------------------------------ |
| `signpost`  | 问医、问火 | 一条判读规则：若甲则你会看到 A，若乙则你会看到 B |
| `exclusion` | 问风       | 三选一里划掉一个假选项，剩下仍是二选一           |

**signpost 类的文本必须与真相无关。** 若按真相分叉写两段文字，玩家一看措辞就知道答案，「有用但不全知」立刻塌掉。测试 `signpost 类谶语与真相无关：措辞不泄底` 会取两个真相相反的种子，断言输出一字不差。

**exclusion 类可以读真相**，因为它只划掉三分之一。测试遍历 120 个种子确认被划掉的**永远不是**真相。

### 二、代价必须是玩家真实做过、且确实无人知晓的事

价目从 `narrative-memory` 中 `visibility === "private"` 的记忆扣取，一定能追溯到 `history` 里一个真实的 choice id。不凭空生成，不接受编造。

> 「因为这是唯一你骗不了我的东西。公事我这里都有卷。你若编一件公事糊弄我，我三卷之内就对得出来。私事不同——私事我查不到，所以你要是肯说，我就知道你是真想要那句话。」

**这条规则最重要的后果：全程循制留痕、事事公开的玩家买不起任何谶语。**

> 「你身上没有我要的东西。你做过的事，我这里都有卷——名册、脉案、开仓令，一笔一笔都在。你没有一件是自己压着的。」
>
> 「这不是坏事。你走的是明路。明路的人问不到天机，也不需要问。将来出了事，替你说话的是记录，不是我。」

这是**取舍，不是门槛**。它把 F01 的五种处世手段接进了一个具体的交易里：`leverage`（藏锋持筹）型玩家有货可卖，`procedure`（循制留痕）型玩家无货可卖但另有依仗。两者没有优劣。

### 三、交出去的秘密会回来

`secret_source:tianji` 成为 E11 延迟后果 `tianji-ledger-called-in` 的**唯一知情渠道**，且 channel 为 `direct`——她确实知道，因为是玩家当面口述、由她落笔记下的。

这笔旧账的特别之处：**它不由敌意驱动。** 关系再好，册子也不会消失；`relationMax` 不生效，唯一的化解方式是册子本身不在了（`tianji_ledger_burned`）。驱动它的只有「不赊」这条规矩。

## 交易时机

每一次交易都必须发生在它所预言的章节**之前**，否则不叫预知。

| 交易 | 宿主场景                      | `fromChapter` | 兑现                |
| ---- | ----------------------------- | ------------- | ------------------- |
| 问医 | 第 4 章 `tianji_trade_ch4`    | 3             | 第 5 章《未落之子》 |
| 问火 | 第 6 章 `tianji_trade_day6_2` | 5             | 第 9 章《十二宫火》 |
| 问风 | 第 8 章 `tianji_trade_day8_2` | 7             | 第 9 章三札分路     |

测试断言每道谶语的 `fromChapter` 严格小于其兑现章节。

## 兑现层：谶语必须真的有用

谶语解锁**动作**，不解锁**结论**。玩家仍要去看、去数、去试；看完之后得到的是**既有的** `known_*` 标签——天机阁不发明新的知识体系，它只是通往同一套知识的第二条路。

| 提示                       | 兑现场景           | 解锁的动作         | 得到                   |
| -------------------------- | ------------------ | ------------------ | ---------------------- |
| `tianji_hint:ledger-ink`   | `day5_2c`          | 只看正月脉案的墨色 | `known_wen_truth`      |
| `tianji_hint:fire-salvage` | `day9_3`           | 火后先数哪一卷完好 | `ch9_patron_confirmed` |
| `tianji_excluded:*`        | `day9_leak_return` | 已知一段是干净的   | 减少一条错路           |

**为什么要有第二条路**：改造前「确定性」这件商品只卖给才学 ≥ 5 的玩家。走人情或胆识路线的玩家，无论多用心都只能一路靠猜。天机阁给了她们一个**用别的东西付账**的机会。两条路都不免费，也都不比对方优越。

**三札分路的处理是反直觉但正确的**：被划掉的选项保留但改写为「（阁中已划去此段）」。谶语减少的是错路，不是增加正路。玩家若仍封查它，会拿到 `tianji_advice_ignored`——你花一件私事换来的话，自己没用上。

## 秘录册的威胁分级

分级刻意做得慢，避免惩罚螺旋。

| 级别        | 条件             | 含义                                       |
| ----------- | ---------------- | ------------------------------------------ |
| `none`      | 0 件，或册子已毁 | 阁中无你的册页                             |
| `noted`     | 1 件             | 单独一件说明不了什么                       |
| `leveraged` | 2 件             | 已经能连成一句关于你的话                   |
| `decisive`  | 3 件及以上       | 比你手里的任何证物都更能决定别人如何叙述你 |

分级**只影响文本口吻**，不额外施加数值惩罚。

## 第十一章：册子回来

宫门前，持伪诏的人没有先拔刀，他取出册子念了起来。每一行都是真的，每一行都是玩家亲口说的。

四条应对，均一次结算并写入 `revenge_answered:tianji-ledger-called-in`：

| 应对                                 | 代价                                          |
| ------------------------------------ | --------------------------------------------- |
| 一行一行认下，说出每件事当时是为了谁 | 无额外损失，但全部公开                        |
| 抢过话头，把没念到的也念完           | 从此再无暗处（`public_truth_self_disclosed`） |
| 用更重的一卷换回册页                 | 需持有空印/鼠册/押记之一；欠录加深            |
| 沉默，让他念完                       | 名望 −2，这几行成为你在别人记忆里的样子       |

卫夷则站在阶下，不解释也不否认：「我从不替人保密。我说过的，是不赊。」

## 副本

- **`tianji-ledger-audit`**（秘录副本 · 欠录）：延迟旧账就绪时触发。她按例知会本人，不勒索。四条应对包括赎回（会被退回，「进了册子的，不用钱赎」）与抢先自述。
- **`tianji-ledger-fire`**（秘录副本 · 火中）：第九章宫火蔓延至西苑。这是**唯一**能让册子消失的机会，但救自己那一架就救不了别人的名字；先扶她出去则册页去向不明，她记得，可她的记忆不能当证据。

## 连续性约束

- 阁主不与高福安功能重复：**高知道消息在谁手里，卫决定那件事以后算不算数。** 高卖流通中的碎片，卫收停止流通的定论。
- 她不预测具体人物的具体行为，只给判读规则与排除。
- 她永远不主动泄露某位玩家的秘密以推进他人剧情；册子只在第十一章被政变方取得，且必须以玩家自己交出过秘密为前提。
- 秘录册不产生可见分数、晋位门槛或自动坏结局。
- 已交出的秘密**不另记一条记忆**——它仍是原来那条私密记忆，只是多了一个 `secret_surrendered:` 标签。这样「你交出去的确实是你做过的那件事」才成立。
- 死者不能新增秘录；若后续为卫夷则增加死亡分支，必须同时登记 `deathTags`。

## 实现

纯派生。不新增 `GameState` 字段、不写入队列、不施加数值效果，全部状态挂在既有 tags 上，因此**旧存档零迁移**。

所有阁楼场景都是**可绕过的侧枝**：从既有场景追加一个选项，走完回到原来的 `next`。一个从不进阁的玩家会得到与改造前完全一致的十二章。
