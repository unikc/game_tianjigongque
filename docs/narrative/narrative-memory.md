# 叙事记忆与处世留痕（F01）

## 玩家命题

系统记住的是玩家反复采用过的手段，不是人格、善恶、能力或唯一流派。五种手段可以并存，也不会直接改变属性、晋位、奖励、选项门槛或结局。

| 内部模式    | 玩家称呼 | 叙事含义                                   |
| ----------- | -------- | ------------------------------------------ |
| `procedure` | 循制留痕 | 借规制、见证与正式记录留下可复核的来处     |
| `leverage`  | 藏锋持筹 | 保留秘密或证据，控制交换与披露时机         |
| `care`      | 护人留路 | 优先保全具体人物、证人、体面或事后退路     |
| `command`   | 当机担责 | 亲自决断、公开承担或以身涉险               |
| `coalition` | 合议借势 | 分权、托付、共同签署或与事之人共同完成事情 |

证据本身不是策略；帝宠属于关系，名望属于结果，均不得计入处世留痕。

## 记忆语法

每条 `NarrativeMemory` 必须包含稳定 ID、章节、场景、来源选择、人物可读事实、当事人、可见范围、状态、至多两种处世手段与来源链。

- 可见范围为 `private | actor | court | public`。其中 `court` 表示该行为进入内廷共同记录，供“宫中如何议论”一类集合查询使用；它不会自动让每个具名 NPC 知情。具名角色仍须亲历、被列为当事人或读取 `public` 记忆。
- `actor` 必须列出确实亲历或获知的角色；私下行为不能被其他 NPC 或“宫中”自动读取。
- 状态为 `active | resolved | superseded`。解决或被后续行为取代不会抹去事情曾发生过。
- 同一选择产生多个结果标签时仍只生成一条稳定记忆。
- E08 文书与 E11 旧账只通过 `provenance` 引用，不复制它们的状态。
- 所有记忆以现有 `history` 中的稳定选择 ID 为事实来源；结果标签只用于判断解决或取代状态，不能反推某项具体行为。不增加存档字段或迁移。

## 形成与展示

- 每种手段按不同记忆 ID 计数，内部最多记为三次；玩家界面不显示数字。
- 至少有两件不同的具名往事相印，才称为已经形成的处世手段。
- 五种手段全都可以并存，不选出唯一“玩家类型”。
- 行录的“处世录”最多展示四种已经形成的手段，每种只引用一件玩家亲自做过的事实。
- 玩家自我复盘文案使用“近来行事”“曾经”“留下脉络”，不用“宫中人已经知道”暗示全知，也不用人格、领导力、绩效、风险偏好、善恶值或最优流派等词。

## 第一批覆盖

基础批次映射第一至第四章的席位名册、毒香脉案、空印与军粮册；E02 仅追加第五／六章四条明确入档或公开的记录供谢明微复核。它包含私下观察、当事人亲历、宫中可见与公开核办四种范围，并为后续 E03／E05／E07 提供同一查询入口。

## 禁止事项

- 不读取 `wenLoyalty`、`arsonPatron` 等种子真相。
- 不因关系高低、属性或玩家持有秘密而凭空生成已观察行为。
- 不用处世留痕直接判定晋位、结局、奖励或动态难度。
- 不把五种模式写成褒贬排序，也不让所有 NPC 共享同一视角。
