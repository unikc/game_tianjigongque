# 延迟复仇后果模型（E11）

## 玩家命题

宫中人不会因为关系数字低便突然“变坏”。延迟复仇必须来自玩家做过、对方确实知道、并等待到合适时机才有能力讨还的一笔旧账。触发只带来一个可回应事件，不自动降位、杀人或判定坏结局。

## 后果语法

每条延迟后果依次经过：

1. **旧因**：玩家做过的可见选择及其章节；同一旧账可积累多个轻重不同的旧因。
2. **知情渠道**：本人亲历、公开发生或由明确证人转述。玩家知道不等于 NPC 知道。
3. **逐因化解**：和解只取消它明确对应的旧因；后续新发生的羞辱、撤职或选边仍可形成一笔新账。
4. **等待时机**：从最早且仍有效的旧因起至少跨过完整章节，直到目标真正有价值。
5. **仍可行动**：死亡、明确偿债、与当前旧因对应的和解或既有解决都会使后果失效。
6. **目标**：位分、名望、证据控制或军令支持之一；不得一次惩罚多个核心系统。
7. **玩家应对**：正面对质、程序处理、交易和解或承担代价；至少三条可达路线且没有零成本完美解。
8. **一次结算**：使用既有支线解决记录和 `revenge_answered:*` 记忆防止重复触发。

运行时由 `src/game/state/delayed-consequences.ts` 纯派生。它不写入新队列、不读取种子真相，也不直接施加数值效果。

## 知情边界

- `wenLoyalty`、`arsonPatron` 及其他确定性种子真相永远不能充当 NPC 的知情渠道。
- `witness_saved` 只说明证人活着，不说明证人已向某人转述。
- 泛化的“真相公开”标签不能自动让所有角色全知；每位发起者必须有自己的渠道条件。
- 关系负值只能控制后果是否仍有敌意或改变力度，不能单独创造旧因。
- 高关系可以化解轻度旧账，但不能自动抹掉重大公开背叛；重大旧因需要明确和解标签。
- 和解标签必须挂在具体旧因上，不能向后覆盖尚未发生的新旧账。

## 连续性约束

- 顾明华夺回的是政治主动权，不是单纯因嫉妒害人。
- 高福安以副本和消息为自己定价、保命，不凭空伪造证据。
- 裴照南以程序和军纪拒绝无记录私令，不写成暗杀者。
- 已故者不能发起新复仇；其遗留文件只形成既成后果。
- 后续若给顾明华或裴照南增加死亡分支，必须同时为对应后果登记明确的 `deathTags`，不能依靠人物显示状态隐式判断。
- 一次事件最多一个主要损失和一个记忆标签；主线始终保留可继续路线。
- 后果结果可以改变关系、证据去向或责任记录，但不能替代现有结局判定。
