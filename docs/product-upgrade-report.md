# 《天机宫阙》本轮产品升级报告

## 核心玩法

- 第 5 章起取消“章节结束即自动晋位”。晋位改为三条既有资源路线：帝心、清议、人脉；任成其一即可晋位，未达标会暂留原位并可在后续章节重试。
- 晋位检查每次最多提升一级，不降级；旧存档原有位分继续保留。
- 帝王关系明确拆分为宠爱与信任。重要选择不再让二者同步上涨。
- 所有剧情选项统一通过一套可用性判断，涵盖属性、位分、命宫、标签、珍藏和人物关系条件。

## 剧情后果

- 第 7 章春猎会分别记录：皇帝受伤、主角受伤、证人获救、传令人落网与证据遗失。
- 第 8 章根据春猎结果出现不同证词路线，并让沈令仪、顾明华记住玩家对凤印名册的处理方式。
- 第 9 章分别记录高福安生死、鼠咬残账、纵火者、宫人网络与幸存者；没有相应证据时，不再显示不合理的公开指控。
- 更新人物、时间线、秘密与未决线索文档，确保后续章节沿用同一套事实。

## 视觉与手机体验

- 章节结算改成 156px 大幅章节画面，标题覆盖在画面上，取代空白文书式结算。
- 晋位成功使用盖印式揭晓；未晋位显示三条路线与缺少条件。
- 320–430px 手机主页行动改为两列，休息独占整行；触控高度至少 60px。
- 奖励图片在手机上放大到 96 × 112px；结果说明、奖励说明与诏书小字提高字号和行高。
- 去掉主页重复的“继续剧情”按钮，并区分帝王关系与今日大事的材质层级。
- 切换寝宫／人物／珍藏／行录时自动回到内容顶部，解决从长列表返回后页面停在半截的问题。
