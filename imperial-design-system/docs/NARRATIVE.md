# Narrative and localization

Scene content should remain data, not JSX. Stable scene/choice IDs survive copy edits and translation. Dialogue components receive speaker, body, choices and feedback; they do not calculate outcomes.

Author for short mobile turns: one dramatic beat per panel, plain choices with distinct intent, and outcomes that explain consequence without judging the player. Humor should emerge from character or bureaucracy, not undercut danger or repeat meme phrasing.

Localization keys must support name variants, rank forms, grammatical context, pluralization and text expansion. Never concatenate translated sentences. Voice scripts include speaker, emotion, pronunciation, timing and subtitle text.
