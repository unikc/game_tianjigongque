# Accessibility

Target WCAG 2.2 AA. Native buttons and disclosures are preferred. Touch targets are at least 44×44px, focus is visible, destructive actions use labeled alert dialogs, outcomes use polite live regions, and progress exposes numeric semantics. Color is never the only carrier of rank or change.

Support 200% text without clipped choices, safe areas, portrait alt text, muted play, reduced motion and keyboard operation. Decorative palace layers are hidden from assistive technology. Test at 320×568 and 390×844 and with screen-reader reading order.
